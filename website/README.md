# NadeSMP Website

This folder contains the static website:

- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — year and Discord invite link

## Configure the Discord link

Open `script.js` and set `DISCORD_INVITE_URL` to the official server invite.

## Hosting

The folder can be deployed as a static site on Vercel. In the Vercel project settings, set the Root Directory to `website`. No build command is required.
